## 3. Initial Platform Setup

### 3.1. Create CloudFlare Resources

Before deploying the Workers, you need to create the necessary CloudFlare resources (KV namespaces and a D1 database).

1.  **Create KV Namespaces**:

    ```bash
    # For tenant configuration
    npx wrangler kv:namespace create TENANT_CONFIG
    npx wrangler kv:namespace create TENANT_CONFIG --preview

    # For rate limiting
    npx wrangler kv:namespace create RATE_LIMITS
    npx wrangler kv:namespace create RATE_LIMITS --preview
    ```

    Take note of the `id` and `preview_id` for each namespace.

2.  **Create D1 Database**:

    ```bash
    npx wrangler d1 create flarecog_analytics
    ```

    Take note of the `database_id`.

3.  **Initialize D1 Database Schema**:

    ```bash
    npx wrangler d1 execute flarecog_analytics --file=./schema.sql
    ```

    Create `schema.sql` with the analytics schema (see Appendix A).

### 3.2. Create Dispatch Namespace

The dispatch namespace is the container for all tenant-specific user Workers.

```bash
npx wrangler dispatch-namespace create flarecog
```

This command creates a dispatch namespace named `flarecog`.

### 3.3. Configure and Deploy the Dispatch Worker

The dispatch Worker is the central router for the platform.

1.  **Navigate to the dispatch Worker directory**:


2.  **Update `wrangler.jsonc`**:

To route traffic to your dispatch Worker, you need to configure a DNS record for your custom domain. Create a wildcard `A` or `CNAME` record that points to your dispatch Worker. For example, if your domain is `flarecog.ai`, you would create a record for `*.flarecog.ai`.

## 4. Tenant Provisioning (Programmatic)

With the platform API deployed, you can now provision tenants programmatically using HTTP requests.

### 4.1. Create a New Tenant

```bash
curl -X POST https://api.flarecog.ai/tenants \
  -H "Authorization: Bearer YOUR_ADMIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "tenantId": "acme",
    "tenantName": "Acme Corporation",
    "tier": "pro",
    "config": {
      "rateLimit": {
        "requestsPerMinute": 600,
        "burstSize": 1000
      }
    }
  }'
```

**Response:**

```json
{
  "success": true,
  "tenantId": "acme"
}
```

The platform API will:
1. Validate the tenant ID
2. Generate user Worker code
3. Deploy the user Worker to the `flarecog` dispatch namespace
4. Store tenant configuration in KV
5. Log the provisioning event in D1
